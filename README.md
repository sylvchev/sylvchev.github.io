My website, based on the [al-folio](https://github.com/alshedivat/al-folio) v1 starter by [alshedivat](https://alshedivat.github.io/al-folio/).

- `site-v1`: Jekyll sources (content in `_pages`, `_news`, `_projects`, `_teachings`, `_posts`, `_bibliography`, `_data`).
- `gh-pages`: built site, deployed by the `Deploy site` GitHub Action.
- `legacy-source` / tag `legacy-site-2025`: the pre-v1 site, kept for reference.

Upstream docs: see `docs/` (INSTALL, CUSTOMIZE, FAQ). To pull upstream updates: `git fetch upstream && git merge upstream/main`.
